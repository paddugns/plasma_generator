# Plasma Generator

This project involves the design and implementation of a basic plasma generator circuit using simple and easily available electronic components. The system operates with a 12 V DC input supply and utilizes a plasma generator module along with resistors and a Bipolar Junction Transistor (BJT) for switching and control purposes.

The BJT acts as a driving element that regulates the current flow required for plasma generation, while the resistors are used for proper biasing and current limitation to ensure safe operation of the circuit. The plasma generator produces ionized gas, known as plasma, which demonstrates high-energy electrical discharge behavior.

This project has several practical applications, including educational demonstrations of plasma physics, ionization processes, and high-voltage principles. It can also be used in air purification experiments, surface treatment studies, sterilization research, and introductory plasma-based electronics learning. The project serves as a foundation for understanding advanced plasma technologies used in industrial and scientific applications.
